# 1. Premise

The **Institute for Analytical Machines (IAM)** is built around a single pedagogical claim: durable technical mastery requires the learner to evaluate their own reasoning before seeking external validation.

# 2. Method of Study

Every study module at IAM follows a three-part loop:

1. **Formulation** — State the problem, assumptions, and expected invariants in plain prose.
2. **Construction** — Build or prove the artifact from first principles.
3. **Self-Evaluation** — Log an honest mastery score (`1–5`) and record precisely where understanding broke down.

# 3. Repository Discipline

All curriculum notes and technical blogs are stored as plain text Markdown inside the institutional GitHub repository (`posts/`). Simplicity in tooling preserves focus on the work itself.
